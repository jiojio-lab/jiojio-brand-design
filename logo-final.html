jio — locked.

Wordmark 定稿 EB Garamond,小写 jio。Mark 定稿汉字 吉。字标颜色 和 印章底色 都绑定到单一 token --accent,默认 Fawn Deep #7A5E3E — 主题换色时 Logo 自动跟随。以下是完整的使用规范。

09
Spec
可复制的完整技术规范。
Accent token
--accent = #7A5E3E (Fawn Deep) on light · #A07E58 (Fawn Main) on dark. Wordmark fill and seal background both read from this token — change one place, both follow.
Wordmark
EB Garamond · weight 500 · lowercase · letter-spacing −0.005em
Wordmark color
var(--accent) — default Fawn Deep on light, Fawn Main on dark
Mark character
汉字 吉 · Noto Serif SC · weight 900
Mark seal
Rounded square · radius 4 / size · fill var(--accent)
Seal inner text
Fill Bone #FAF8F2 on light, Bark #2D271C on dark
Mark inner padding
≈ 12% of side on all four sides (character optically centered)
Clear space
X = mark height ÷ 4 · no element or edge within 1X in any direction
Min size
Mark 16px · Wordmark 14px · Lockup 20px mark height
Lockup divider
1px · #C2BFB2 (light) / #5F574A (dark) · height = mark height × 0.75
Lockup gap
Mark → divider: 1X · divider → wordmark: 1X
Motion · stamp
rotate(−3°) · scale 1 → 1.15 → 1 · 2s · ease-out · opacity 0 → 1 in first 25%
