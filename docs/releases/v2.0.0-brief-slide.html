01 · 概念对齐

设计系统是什么：4 组 12 个 tab，加三层令牌

左边是内容：品牌、基础、界面、体验四组共 12 个 tab，在同一页的侧栏里切换。右边是机制：主题色等共享值经「原始值 → 语义名 → 组件取值」三层令牌联动，换一个主题色，logo 和按钮一起变；组件内部仍有直接写入的尺寸。

关键认知：一个出发点

把人和他要做的事之间的噪音去掉。12 个 tab 的每条规则都是这句话的推论，所以它们读起来像同一个声音。

对本项目的意义

jiojio 的产品、网站、文档都从这一份取色取字，新协作者不用问人。它也是 jiojio 对外的品牌门面，所以本版的公开化收口和设计内容同样重要。

02 · 本版新名词

先把名词说清，再讲变更

设计系统 design system
把品牌的颜色、字体、间距、组件和使用规则写成一份可查的文档。本版：整份文档就是本仓库的内容。
设计令牌 design token
给每个设计决定起个名字，改一处，处处跟着变。本版：Tokens tab 能导出 W3C JSON 与 CSS 变量。
Fawn 与 Ink accent rule
Fawn #A07E58 是唯一强调色，表示输出与交互；Ink #16140F 表示输入与事实。本版：logo 色值对不上它（见决策点）。
Paper 与 Bark canvas colors
亮色底 #FAF8F2、暗色底 #2D271C，都是暖色，不用纯白纯黑。本版：本页配色就取自它。
字标与印章 wordmark / seal
小写 jio 字标加「吉」字印章，二者都绑 --accent。本版：MIT 许可明确不覆盖它们。
MIT 许可 MIT License
最宽松的开源许可之一：可以复制、修改、再分发，只需保留版权声明。本版：新增，代码与文档适用，品牌资产除外。
历史重写 git filter-repo
改写仓库里每一个已有 commit，所有 commit 编号随之改变。本版：用它清除了历史中的个人邮箱与个人账号地址。
noreply 邮箱 GitHub noreply address
GitHub 提供的替身邮箱，commit 里写它，真实邮箱就不会公开。本版：两个早期 commit 的作者邮箱改成了它。
03 · 背景

为什么是现在：仓库在 2026-10-05 从私有转为公开

设计系统 4 月写成后一直在私有仓库里。转公开意味着任何人都能 clone 全部历史和文件，有些东西一旦公开就收不回，所以必须在公开前后一次收口，并给出一个干净的、可对照的版本基线。

本页关于转公开日期、早期 commit 邮箱与隐私审计的叙述，据总工程师 2026-10-05 session 记录，未在本次评审中复核。

现状：公开前的问题

  • 2 个早期 commit 的作者邮箱是个人 Gmail
  • 旧 README 含指向个人账号的 clone URL
  • 7 个页面的页头编号与侧栏不一致
  • logo 规范页有 1 处死链
  • 没有 LICENSE；README 是内部口径

影响

公开仓库的历史对所有人可读。邮箱写在 commit 里，无法事后撤回；首批访客看到的第一屏是内部口径的 README，第一次点击可能就是 404。

机会

转公开是天然的收口点：一次补齐门面、许可、一致性和隐私，给 v2.0.0 一个干净的基线，后面每个 release 都能对着它说「这一版改了什么」。

06 · 代表性详解

影响面最大的一项：F6 历史重写

Before2 个早期 commit 的作者邮箱：个人 Gmail
旧 README 的 clone URL：github.com/个人账号/…
After当前可达 commit 的作者与提交者邮箱：noreply 地址（GitHub 与 Anthropic 两个域名）
clone URL：github.com/jiojio-lab/jiojio-brand-design

1修了什么

用 git filter-repo --mailmap 把两个早期 commit 的个人邮箱改成 GitHub noreply 地址，用 --replace-text 把旧 URL 换成组织地址，然后 force push。

2为什么这样修

邮箱写在 commit 对象里，公开后任何人 clone 就能读到，删文件删不掉历史。只有在公开前重写才不会留下已扩散的副本。

3不修会怎样

个人邮箱永久留在公开历史，每个 clone 与 fork 都带一份，会被爬虫收集用来发垃圾邮件与社工；个人账号地址让公开仓库与个人身份挂钩。

4delta 在哪

确定性：历史里不再出现个人邮箱。度量：git log --format='%ae%n%ce' | sort -u 只含 noreply 地址（GitHub 与 Anthropic 两个域名）。遗留：旧 SHA 仍可按 URL 访问，等 GitHub support 清除。

其余各项同格式四问详解，见 release 页面（v2.0.0-release.html）。
